# Примеры использования

Примеры промтов для работы с Kaiten через Claude. Команды формулируются свободным
текстом — ниже типовые сценарии по всем 28 инструментам.

## Базовые операции

```
Покажи карточку 789
```

```
Создай карточку "Исправить баг" на доске 456 с описанием "Проблема с авторизацией"
```

Создание требует `board_id`. Колонку, дорожку, тип и ответственного можно не
указывать — применятся значения доски по умолчанию. Чтобы задать их явно, сначала
узнайте ID через справочники (см. ниже).

```
Переведи карточку 789 в работу
# state: 1 = в очереди, 2 = в работе, 3 = готово
```

```
Назначь ответственным за карточку 789 пользователя Vladimir
```

Обновляются только переданные поля, остальные остаются как есть.

```
Удали карточку 789
```

Удаление **необратимо** — карточка, её комментарии, история и связи пропадают для
всех. Если данные могут понадобиться, лучше архивировать (перевести в готово /
убрать с активной доски).

## Метки (теги)

```
Добавь карточке 789 метки "tech_debt" и "backend"
```

Метки задаются по имени; если метки ещё нет — она создаётся и привязывается.

```
Убери с карточки 789 метку "backend"
```

Имена сопоставляются без учёта регистра с текущими метками карточки.

## Поиск

Основной инструмент поиска — `kaiten_search_cards`. Возвращает компактные строки,
отсортированные по дате создания (новые сверху).

```
Найди карточки со словом "авторизация" на доске 456
```

```
Покажи мои карточки
# Фильтрует по owner_id текущего пользователя
```

```
Покажи просроченные карточки на доске 456
```

```
Найди срочные (ASAP) карточки в пространстве 123
```

```
Найди карточки в работе на доске 456
# state = 2
```

```
Покажи карточки, созданные после 1 мая 2025 на доске 456
```

```
Найди 20 карточек на доске 456, отсортированных по дате обновления
```

```
Покажи архивные карточки на доске 456
# condition = 2
```

### Поиск по русскому тексту

Kaiten хранит русский текст в исходных словоформах, а поиск идёт по подстроке.
Ищите по **корню слова**, а не по полной форме:

```
Найди карточки про "болгар"
# Найдёт "Болгарии", "болгарский" и т.п.
```

### Параметры поиска

- `query` — частичное совпадение по названию / описанию / комментариям
- `board_id` — рекомендуется: держит выдачу компактной и быстрой
- `space_id` — по умолчанию default space; `0` = все пространства (медленно)
- `state` — `1` = в очереди, `2` = в работе, `3` = готово
- `owner_id` / `owner_ids` / `member_ids` / `tag_ids` — фильтр по людям и тегам
- `column_id` / `lane_id` / `type_id` — фильтры по структуре доски
- `asap`, `overdue` — только срочные / только просроченные
- даты (ISO 8601): `created_*`, `updated_*`, `due_date_*` (`_before` / `_after`)
- `condition` — `1` = активные (по умолчанию), `2` = архивные
- `sort_by` — `created` (по умолчанию), `updated`, `title`
- `sort_direction` — `asc`, `desc` (по умолчанию)
- `limit` — количество карточек (по умолчанию 10, максимум 20)
- `skip` — пропустить N для пагинации

Для полной детализации одной карточки используйте `kaiten_get_card`.

## Default Space

По умолчанию все операции выполняются в пространстве из `KAITEN_DEFAULT_SPACE_ID`.
Это делает команды короче:

```
Найди карточку про Болгарию
# Автоматически ищет в DEFAULT_SPACE_ID
```

Для поиска во всех пространствах укажите это явно:

```
Найди карточку про Болгарию во ВСЕХ пространствах
# space_id = 0, медленно
```

## Подзадачи и связи

```
Покажи подзадачи карточки 789
```

```
Привяжи карточки 801 и 802 как подзадачи к карточке 789
```

```
Отвяжи подзадачу 802 от карточки 789
# Связь снимается, сами карточки не удаляются
```

```
Покажи, в каких карточках 789 является подзадачей
# Родительские карточки
```

Массовые операции делают по одному вызову на каждый ID и не прерываются на первой
ошибке — в ответе будет `succeeded` / `failed`.

## Участники и ответственный

```
Покажи участников карточки 789
# type 1 = участник, type 2 = ответственный
```

```
Добавь пользователей 11 и 22 в участники карточки 789
```

```
Назначь ответственным за карточку 789 пользователя 11
# Если не участник — добавится автоматически
```

```
Сними пользователя 11 с карточки 789
# Снятие ответственного = удаление из участников
```

## Комментарии

```
Покажи комментарии карточки 789
# Свежие сверху: по умолчанию 50, максимум 100; offset листает старые
```

```
Добавь комментарий к карточке 789: "Работа завершена"
```

```
Измени комментарий 555 на карточке 789: "Уточнение: завершено частично"
# Новый текст полностью заменяет старый; редактировать можно только свои
```

```
Удали комментарий 555 на карточке 789
```

## Пользователи

```
Покажи, под каким аккаунтом я работаю
# kaiten_get_current_user — проверка токена, свой user_id
```

```
Найди пользователя Saranyuk
```

Kaiten хранит имена **только латиницей** — кириллицу нужно транслитерировать перед
поиском (Владимир → Vladimir, Сергей → Sergey, Юлия → Yulia). Поиск без запроса
выгружает до 100 пользователей, поэтому всегда указывайте имя или email.

## Справочники (для корректных ID)

Перед созданием/перемещением карточек получите валидные ID структуры доски:

```
Покажи доски пространства 123
```

```
Покажи колонки доски 456
```

```
Покажи дорожки и типы карточек доски 456
```

## Управление детализацией (verbosity)

Параметр `verbosity` поддерживают `kaiten_search_cards`, `kaiten_list_boards`,
`kaiten_list_users`, `kaiten_get_card_children`, `kaiten_get_card_parents`,
`kaiten_get_card_members` и `kaiten_get_card_comments`.

**minimal** — ультра-компактно (экономия до 90 %):

```
Найди карточки на доске 456 с minimal verbosity
# Вывод: 1. [12345] Fix bug
#        2. [12346] Add feature
```

**normal** — сбалансированный, по умолчанию (экономия ~80 %): owner, board, статус, URL.

**detailed** — полный API-ответ со всеми метаданными:

```
Найди карточки на доске 456 с detailed verbosity
```

Когда что использовать:

- `minimal` — быстрый поиск, получение ID, краткие списки
- `normal` — обычная работа с карточками (по умолчанию)
- `detailed` — отладка, интеграции, когда нужны все поля

## Формат ответа

`kaiten_get_card` поддерживает выбор формата `format`:

```
Покажи карточку 12345
# markdown (по умолчанию) — человеко-читаемый вид
```

```
Покажи карточку 12345 в JSON формате
# структурированные данные для интеграций и парсинга
```
